An async Rust API and command-line tool for the ELK-BLEDOM / MELK family of
Bluetooth LE LED strips, built against a MELK-OA10 WS2812B RGBIC strip. Power,
colour, brightness, speed, patterns and the music-reactive mic modes are all
implemented and verified against real hardware.

Small, finished, and documented — and built with significant LLM assistance.
